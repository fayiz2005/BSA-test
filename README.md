# BSA UBC Website (In Development)

A modern, responsive website for the **Bangladesh Student Association at UBC (BSA)**.  
Built with **Next.js** and deployed on **Vercel**.

**Live Demo:** https://bsa-test.vercel.app/  
**GitHub:** https://github.com/fayiz2005 (replace with the exact repo link)

---

## Overview

This project aims to replace an outdated Wix site with a faster, more maintainable website that makes it easy for students to find:

- Club announcements
- Upcoming events
- Executive team information
- Contact links and resources

---

## Tech Stack

- **Next.js** (React)
- **Tailwind CSS**
- **Vercel** (deployment)

---

## Features

- Responsive UI (mobile-first)
- Pages for club info and executive profiles
- Event / announcement sections (in progress)
- Clean, maintainable component structure
